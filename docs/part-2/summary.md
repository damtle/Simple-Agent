# 第二部分总结

第二部分把模型生成与程序执行连接成了全书第一个完整 Agent Loop。

| 组件 | 接收什么 | 产生什么 | 核心责任 |
|---|---|---|---|
| Action Protocol | 用户目标与当前上下文 | 结构化行动请求 | 规定模型可以怎样表达下一步 |
| Parser | 不可信模型文本 | `AgentAction` 或明确错误 | 阻止非法输出直接进入执行 |
| Tool Executor | 已校验 Action | Tool Result | 由程序掌握真实执行权 |
| Observation | Action 与 Tool Result | 模型可读的环境反馈 | 让执行结果影响下一轮决策 |
| Agent Loop | 目标、消息和终止边界 | 多步执行或明确停止 | 持续推动整个闭环 |

完整的数据流是：

```text
用户目标
→ 模型输出
→ Parser
→ AgentAction
→ Tool Result
→ Observation
→ 下一轮模型调用
```

这里有两条必须长期保持的边界：模型拥有语义上的选择权，程序保留真实执行权；工具结果只有进入下一次请求，才真正成为 Agent 的观察。

到此，系统已经能够完成多步任务，但控制方式仍然比较通用。下一部分不再增加更多工具，而是比较局部决策、整体规划和结果修订三种不同问题。
