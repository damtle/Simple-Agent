# 第一部分总结

第一部分没有急着引入完整 Agent，而是先把后续章节都要用到的四层基础搭好。

| 层次 | 已经建立的能力 | 仍然存在的限制 |
|---|---|---|
| Agent 基础 | 用目标、环境、观察、行动和循环描述系统 | 规则决策只能处理预先写好的条件 |
| LLM | 根据消息理解开放语言并生成回答 | 一次调用看不到先前对话 |
| `messages` | 让历史消息成为下一次调用的上下文 | 仍然只能使用输入中已有的信息 |
| Tool | 通过 Python 函数读取数据或完成确定性操作 | 工具仍由开发者手动选择 |

这一部分最重要的区分是：

```text
模型生成了一段文字 ≠ 程序执行了一项操作
```

LLM 可以表达“应该查询天气”，但不会因此自动读取天气数据；工具函数可以查询数据，但也不会自动被模型选中。模型与程序已经分别拥有生成能力和执行能力，却还缺少一份双方共同遵守的行动协议。

下一部分将让模型输出结构化 Action，由 Parser 决定它能否进入工具执行，再把结果转换成 Observation。只有这条连接建立后，模型判断与程序执行才会形成真正闭环。
